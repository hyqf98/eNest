# eNest 通用插件体系整改与验收

日期：2026-10-13。范围为本次实施开始时工作区内的宿主通用设施和自动枚举的 35 个插件；保留已有未提交修改，不提交或推送。插件仓库是独立 Git 仓库。DSH 专属业务和外部 Node runtime 不纳入通用页面沙箱保证。

后续根据用户要求完成[能力与权限收口](PLUGIN_PERMISSION_CLOSEOUT.md)：插件私有基础能力直接可用，只对敏感资源访问授权；同时补齐所有插件的权限设置入口，以及设置、密钥库、主题边界修复。以下性能数据与上一阶段测试计数保留原执行时点，追加测试以收口报告为准。

## 修复内容

| 范围 | 已落地行为 |
| --- | --- |
| 工程与包 | 单一 `plugins/<id>` 源码标准；根级 manifest/package/入口，src 与 public/assets；构建只写 dist。`.enestplugin` 根直接是 dist 内容，固定命名；源码、产物、安装器共用 schema。拒绝旧嵌套目录、越界、符号链接、源码/环境配置混入 |
| 全部官方插件 | workspace 自动枚举构建；共享 kit 为依赖，SDK/工具在插件仓库。迁移旧路径、补齐实际调用权限、修复无效容器查询/横向溢出、补独立 SVG 图标、包内说明和运行截图 |
| 开发加载 | 源码、框架服务器、dist 预览明确区分；目录选择后直接打开、不复制安装。IP/端口/URL 覆盖只写开发注册。删除递归监听；HMR 由开发者启动的框架负责 |
| 沙箱与 IPC | 自包含 CJS preload；sandbox/contextIsolation 开启、Node 关闭；插件校验身份、主 frame、入口与运行代次；shell/Quick/orb 校验可信窗口对象、主 frame、预期文档及角色通道。浏览器敏感权限、下载、任意导航/外联默认拒绝 |
| 权限与系统能力 | 原生串行授权，取消/超时/关闭不遗留允许；拆分读写/系统查看控制/配置读写/SSH agent。危险操作确认真实目标，不信任 confirmed:true。剪贴板历史仅长期授权后采集 |
| 文件与数据库 | 选择器签发私有文件句柄，绑定插件、用途与代次；本地文件读取有大小/并发限制。SSH、CSV、数据库、图片/文本导入迁移句柄；SQLite authorizer 和 DuckDB 配置锁定防 SQL 文件旁路 |
| 生命周期 | 修正切换前台身份与闲时计时顺序、隐藏/最小化/恢复；保持三分钟、六实例软上限、LRU、lease/开发例外。启动会话恢复前不写回临时 Tab；关闭/崩溃/休眠/重载/停用/卸载释放所属代次资源；已授权宿主后台任务按专属生命周期管理 |
| 安装一致性 | 复制后重新校验暂存树及 manifest 快照，再原子发布；市场包校验 ID/版本，索引提供 SHA256 时校验摘要；更新失效旧缓存，取消、替换失败、卸载竞态均有回归 |
| 展示与主题 | 安装版本的图标、README、截图按其包读取；索引与预览媒体从最终 ZIP 提取。classic/orb Tab 接收真实包图标，动态标题/文字图标/角标由宿主快照同步，休眠保留、关闭清除。Markdown 限制链接/相对资源，保留异常图标降级；主题注册/撤销清理按来源处理 |
| 数据 | 默认 `~/.eNest`，保留显式数据根；当前机器未发现旧 `~/eNest`。迁移代码在内容与 SQLite 完整性验证成功后才删除来源，失败保留来源 |
| 文档与 skill | 16 篇权威开发指南同步到插件仓库；133 项生成类型，无写入检查模式；`skills/enest-development` 按宿主/插件/主题/调试/打包分流，并有独立从零开发演练 |

额外修复包括两款插件初始化函数未调用被构建裁掉、WebSocket 二进制/取消订阅、市场畸形 ID/版本/分类防御、文件重命名范围、网络流/SSE/存储字节预算，以及主题 Token 键的 CSS 注入边界。

## 验证证据

以下按验证层分开；浏览器预览 fixture 不代表真实 Electron 或外部服务通过。

- **宿主集成**：完整 `npm run typecheck` 和 `npm run build` 通过；安装格式、市场资源、IPC、迁移、开发注册、Markdown、生命周期、存储和设置/Quick 等最终集成回归 100/100 通过。SDK 声明类型检查、生成文件检查、文档同步检查与 skill 校验均通过。
- **全部插件**：逐个构建、打包、解包，35 个包的摘要/索引及 105 个必要媒体文件核验通过；83 个不同插件仓库测试全部实际执行通过，35 × 6 = 210 个浏览器模式/尺寸/字号组合通过。逐插件记录、命令、包摘要和截图见插件仓库 [验收矩阵](../../eNest_plugin/docs/PLUGIN_AUDIT_2026-10-13.md)。
- **原生运行**：临时数据根、独立 profile、真实 Electron 与生产 preload；35 个发行插件逐个打开/关闭，检查 sandbox、无 Node、资源/CSP/未处理异常及释放计数。该夹具允许 storage/settings/ui/vault/theme，拒绝 OS/network 能力，只覆盖启动、主题注册/禁用与关闭清理。原始结果见 [官方插件原生冒烟](official-plugin-native-smoke-2026-10-13.json)。
- **开发与布局**：点击开发控制台“选择源码目录”，原生目录对话框 stub 返回仓库外临时目录，验证生产按钮和 store 自动打开，无单独 open 调用、不安装源码；Vite 同一 WebContents HMR、显式 dist 预览、连接失败及重试均通过。主窗 900×600、1200×800、1920×1080 和 150% 基础字号，首页/设置主容器无横向溢出。见 [开发与布局记录](plugin-native-dev-layout-2026-10-13.json)。
- **Tab 展示**：classic/orb 原生检查包图标实际加载、动态标题/文字图标/角标、空值恢复默认、非法输入拒绝与关闭重开后的清理。见 [Tab 图标记录](plugin-native-tab-icons-2026-10-13.json)。
- **权限与攻击面**：跨插件/过期句柄、拒绝/撤权/晚到授权、恶意 origin、浏览器直连、SQLite/DuckDB 实际引擎文件攻击、SSH 认证/归属 fixture、本地 WebSocket/代理服务、原子安装与主题撤销，见 [安全报告](PLUGIN_SECURITY_VALIDATION.md)。另用临时 loopback OpenSSH 和生产主进程服务验证密钥句柄认证、SFTP 读写/冲突、256 KiB 上传下载、断开重连与资源回收；服务和临时密钥已清理，见 [实测结果](plugin-local-openssh-2026-10-13.json)。
- **生命周期与性能**：默认 180 秒真实切换休眠、草稿恢复；50 轮开关、六实例上限、进程回收、冷创建/暖切换/闲时 CPU 与内存；详见 [生命周期与性能报告](PLUGIN_SANDBOX_LIFECYCLE_VALIDATION.md)。
- **编译缓存**：[缓存探针](plugin-code-cache-2026-10-13.json) 验证启用后产生编译缓存文件，并在 Electron 重启后保留；更新失效有安装回归。未收集 V8 cache-hit 计数，不能仅据文件存在声称命中率或加速比例。
- **skill**：结构校验通过，独立临时工程从零完成 notes 插件、SDK checkJs、Vite、存储失败处理、模式切换、截图和 ZIP；见 [演练报告](../../eNest_plugin/docs/skill-forward-validation.md) 与 [SKILL.md](../../eNest_plugin/skills/enest-development/SKILL.md)。

## 验证边界与剩余验收

- macOS 已原生测试；Windows/Linux 的原生窗口、系统权限和稳定性未实测。
- Electron 的权限回调不能拦截全部 HTML 文件输入/拖放；这些是用户在浏览器中明确选择所授予的能力。官方插件已用宿主接口，不能声称任意第三方页面所有文件选择都经过 eNest 权限弹窗。
- 未连接用户真实 SSH、数据库、中间件或 DSH 服务。临时本地 OpenSSH 的真实传输与主进程服务已实测，但权限 UI/vault/事件投递采用 fixture；旧 Linux 集成套件仍跳过，资源采集、多跳、SSH agent 未做真实集成。实际 SQLite/DuckDB 引擎与本地受控网络/代理服务已测试，真实外部服务、系统屏幕权限和 DSH 内部工具仍需对应环境验收。
- 原生自动化的权限对话框响应使用可控 stub，并验证生产授权路径、队列和代次；不把它描述为人工点击每一种系统授权对话框。
- 50 轮回收及短时间 CPU/RSS 采样不证明数小时/数日无泄漏；可见帧性能和严格修复前后 ≤20% 回归门槛尚未完成。

实现和当前环境验证已记录；上述未覆盖项保持明确，不作为“全部验收通过”交付。
