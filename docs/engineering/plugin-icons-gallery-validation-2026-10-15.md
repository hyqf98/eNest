# 插件图标与详情截图修复验收

日期：2026-10-15。范围：宿主插件图标展示、插件详情截图画廊，以及独立 `eNest_plugin` 仓库中的图标和截图素材。

## 问题与修复

### 图标

23 个官方插件的 SVG 使用透明背景和浅色 `#e6edf7` 线条。图片加载成功，但在浅色主题中对比度不足，看起来像没有图标。已在原图形下加入 `#1c2330` 圆角底板，保留原来的路径和强调色；其余已有底色或深色线条的图标不变。

宿主为这 23 个已知官方插件的旧素材提供相同背景兼容，覆盖市场、详情、Quick、圆轨和独立窗口的图标选择器。规则限制在相应图片元素，避免影响设置中的圆轨示意图或其他插件。

离线市场此前只有少数专用图形，多个插件重复使用通用图标。现使用 15 个真实 SVG 快照；插件仓库新增 `scripts/sync-shell-plugin-icons.mjs`，支持生成及 `--check` 一致性检查。详情头部复用 `PluginIcon`，加载失败时显示可读的文字回退。

素材维护约定见插件仓库 `docs/PLUGIN_ICONS.md`。

### 详情截图

新增 `PluginScreenshotGallery`，按 manifest 顺序展示去重后的截图，最多 8 张：

- 常驻左右按钮、张数、可点击缩略图；聚焦画廊后支持左右方向键，首尾循环。
- 点击图片打开原生大图对话框，大图与详情同步切换。Escape 只关闭大图，保留详情并恢复焦点。
- 单图隐藏切换按钮和缩略图；无图提供说明；失败图提供重试，并允许继续浏览其他图片。重试保持原 URL，兼容签名和 `enest://` 资源。
- 图库放在详情滚动正文顶部，图片完整显示，不裁切；样式适配深浅主题、窄窗口、三档动画和减少动态效果偏好。
- README 中与图库重复的图片按解析后的 URL 去重，避免同一截图出现两次。

原有 manifest 均只提供一张图，单加切换控件不会产生更多内容。本次为 4 个插件增加 6 张 WebP：剪贴板图片和文件视图、数据库数据和结构视图、SSH 远程文件视图、屏幕助手标注视图。前 5 张采自真实插件构建配合隔离演示数据；屏幕助手复用已核验的真实截图。文件来源和顺序见插件仓库 `docs/MARKET_SCREENSHOTS.md`。

## 实际浏览器验收

通过 CUA 操作实际 renderer，预览宿主 API 使用隔离 fixture，读取当前插件 manifest 和本地素材。未修改用户已安装插件或业务数据。

| 场景 | 观察结果 |
| --- | --- |
| 浅色与深色市场图标 | JSON、编解码、Cron、文本对比等清晰可见；彩色图标保留原貌 |
| 剪贴板多图 | 左右按钮、缩略图、键盘右键切换成功，张数与图片同步 |
| 大图 | 3→1 循环切换成功；Escape 关闭大图后详情仍在，焦点恢复 |
| README 去重 | 与图库重复的图片节点数为 0 |
| 首图失败 | 显示错误与重试，仍可切换有效图片；大图切回坏图再关闭，焦点回到画廊 |
| 图标失败 | 详情显示可读的“剪”字回退 |
| 无截图 | 显示“此插件暂未提供功能截图” |
| 单张截图 | 显示 1/1，没有下一张按钮 |
| 390×844 深色窄窗口 | 页面和详情无横向溢出；大图宽度 370px，切换与关闭可用 |
| 1280×720 浅色、1440×900 深色 | 详情图片和控制区可用，完成视觉检查 |

独立静态审阅后修正了图标失败回退对比度、坏图切换后的焦点恢复，以及 `.orb-icon` 误匹配设置示意元素的问题。

## 验证与交付边界

- 浏览器验证覆盖实际组件与隔离演示数据，不等同于 Electron 原生窗口、`enest://` 协议或远程市场端到端验证；本轮未运行原生 Electron 验收。
- 新增 `PluginScreenshotGallery.test.mjs` 为显式启用的浏览器测试入口，本轮未完成其整套自动测试，不计入上述 14 个通过的测试。
- 没有运行全仓库所有回归测试。以上结果仅代表列出的检查。
- 新素材已进入源码及本地构建产物，尚未发布。旧安装包需要通过后续插件更新获得新增截图；宿主兼容背景可改善旧版官方浅色图标的显示。
- 当前只有上述 4 个插件补充了多张素材；其他插件按各自 manifest 提供的截图数展示。

本次临时预览地址为 `http://127.0.0.1:4180/?theme=light`，仅在本地预览服务运行期间可用。
