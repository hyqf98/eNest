# 设置内容穿过透明标题栏与毛玻璃卡片

## 修改

- ShellLayout 标注当前 `data-shell-view`。只有 settings 状态的 stage 跨整个 app-chrome 网格，从 y=0 开始；标题栏维持独立上层及已有稳定悬停区。
- 设置内容的初始顶部留白增加固定 36px，留白随页面滚走，卡片可以实际滚到标题栏背后；不使用随自动隐藏变化的 8/36px 动态间距，避免 hover 时正文跳动。窄屏简写同步处理。
- 设置 stage 建立低层级 stacking context，限制卡片内菜单不越过标题栏；插件和首页仍按原生视图的边界逻辑布局，没有改为 DOM overlay。
- 移除设置页整页模糊遮罩及实白/氛围卡片的高优先级覆盖。白卡与账户卡改成半透明主题表面，独立圆角伪元素提供 12px blur、轻饱和与内高光，不模糊控件/文字或把它们变成滤镜后代。
- 深色使用更厚的暗色材质，低动画档和减少动态效果降低模糊；减少透明度/高对比度使用近实色无模糊。无 backdrop-filter 支持时使用主题实色回退。
- 卡片 hover 不做位移，避免原生选择器错层或磨砂采样跳动；激活态控件颜色维持原契约。
