# eNest 原版默认主题恢复

日期：2026-10-19。此记录取代同日过渡版晨光的视觉验收，不撤销已经建立的 Workspace、设置描述符和权限隔离标准。

## 本轮范围

用户要求将改动之前的布局、样式、动画、背景、主题色和全部外观设置封装成内置默认主题插件。实现以当前仓库 `HEAD 04580b4` 的原页面和仍在使用的组件、样式、背景引擎为依据；不是恢复整仓快照，不覆盖既有 Quick、市场或业务插件改动。

- 唯一内置身份为 `enest.builtin / default`；默认插件同时声明主题及配套首页贡献。`builtinThemes.ts` 只做注册适配，不另造一份默认配置。
- 默认 Workspace 恢复原市场标题、搜索、精选轮播、分类、已安装卡片、卡片展开详情和顶部 Tab 设置布局。共享纯展示组件保留原 CSS 和 GSAP，业务动作通过受限 bridge 执行。
- 恢复原中性灰 / 石墨、铜橙强调、深浅模式、语义色微调及 Alpha；恢复原字体选项、中英双槽、导入/删除和字号比例。
- 恢复五种原背景动效 `fold / aurora / orbit / ripple / tunnel`，默认 `tunnel`；恢复八种渐变、纯色、图片/视频、透明度、填充方式、品牌/主题/自定义图片开屏及预览。
- 所有外观设置仍由默认主题 Schema 在主题 Tab 中动态渲染；通用设置不恢复第二套外观表单。Profile、revision、生命周期和 owner/activity 检查保持单一权威。
- 旧默认设置迁入新的 default Profile；已有 default Profile 和显式重置优先。旧 profile、quarantine 和不可变迁移备份保留；旧文件路径只由宿主转换为受控公共资源句柄。
- 旧 V1 pack 来源背景在注册表就绪后仅完成一次迁移；来源未就绪时不阻断默认主题，显式背景修改或重置取消待迁移项，提交失败不修改原配置。

## 标准与安全

- 默认 UI 位于 `src/renderer/themes/default/`，仅获得 `enestWorkspace` / 兼容别名 `enestHome`；无 shell API、Node、完整 settings store 或业务插件实例。
- `ready`、路由 ACK、generation、revision、隐藏撤权、资源回收、提供者替换与崩溃回退沿用同一宿主生命周期。
- 搜索到禁用插件只打开详情，不静默启用、运行或安装。详情使用安全 Markdown 和已声明截图；不执行包内 HTML，不开放任意远程图片或外链跳转。
- 背景预设切换复用工作区，不重建业务插件。静态效果缩略图不分配 WebGL；真实背景负责隐藏/失焦/减少动态效果暂停及释放。
- 字体删除仅清理引用该字体的 schema 字体字段，不误清普通字符串设置；删除持久化成功后才回收字体文件。
- 启动预览通过固定宿主动作隐藏原生 Workspace，关闭后回到同一设置实例，不向主题开放任意 shell 事件。
- API、canonical schema 和开发文档同步更新；新的第三方主题实现应从 `docs/engineering/THEME_STANDARD.md`、`docs/site/plugin/themes.md`、`docs/site/plugin/home.md` 开始。

## 启动等待与缓存补充

用户追加要求：正常启动不要显示「正在准备首页」，并检查配置缓存与性能。定位到的问题不是每次读配置都查库：设置和注册表已经常驻主进程内存，外观也已有解析缓存；原流程却在 Splash 结束后才初始化原生工作区，壳又未等待路由 ACK 就展示了准备页。

- 已确认主题在 Home IPC 注册后隐藏预热；原开屏动画、壳配置读取及轻量会话恢复并行。首次选卡仍由显式确认控制，不提前运行未选择的主题。
- 正常加载不渲染 ThemeSetupScreen 或 HomeRecovery；它们仅负责首次确认或真实错误。开屏结束前必须完成 ready、目录 ACK 和事务提交，慢加载时保留已完成的 Logo；跳过/减少开屏动画也不会跳过就绪门禁。
- 正式显示直接复用预热的原生实例。配套首页失败时等待默认主题回退完成再交接；默认回退也失败时保留可重试错误。新恢复锁或更新的导航意图使旧等待失效，不会被旧启动请求解除。
- 初次外观读取合并在途请求，移除独立 Tab 样式重复读取；会话恢复复用本次保存的插件 ID，独立窗外壳恢复不阻塞就绪首页。后续外观变更继续按 revision 拉取，不使用跨代次或磁盘快照冒充初始化完成。
- 一次外观 snapshot 的服务层读取由 2 次减为 1 次，注册表全量 list/clone 由 5 次减为 1 次，最终 DTO 只 clone 一次再深冻结；保持资源授权、失效与写后发布语义。没有将完整设置、字体路径或授权结果缓存到主题页面。
- 原生圆轨的首次同步等壳完成启动；开屏预览/壳卸载显式隐藏已存在的 rail/dock，结束后恢复同一实例。临时可见性提示不能修改权威 Tab 样式或持久化 Profile。
