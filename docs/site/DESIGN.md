# eNest 官网设计记录：模块化工具桌

更新日期：2026-10-14。本文记录本轮已批准方案及实现约定；浏览器验收结果应另行记录，不能从设计规格推定为已通过。

## 目标与视觉语言

核心文案：**把常用工具，放进同一个工作台。**

面向同时处理日常事务与开发工作的桌面用户，用「聚合 → 展开 → 使用 → 个性化」讲清 eNest 的价值。保留真实产品标志、插件图标和软件界面，以大标题、细分隔线、浅浮雕模块与带透视的软件窗口建立桌面触感。下载入口在首屏直接可用。

| 语义 | 浅色 | 深色 |
| --- | --- | --- |
| 页面背景 `--bg` | `#F1F0EC` | `#20221F` |
| 正文 `--ink` | `#242522` | `#EEEEE8` |
| 次要文字 `--muted` | `#686A62` | `#A5A89C` |
| 强调 `--accent` | `#D95B2B` | `#F18052` |
| 表面 `--panel` | `#FAF9F6` | `#292C27` |
| 分隔 `--line` | `#D6D6CE` | `#41463D` |

- 中文使用本地 Noto Sans SC 子集，拉丁字符使用 Manrope，字体加载失败时回退到系统字体；均设置 `font-display: swap`。
- 内容最大宽度 1320px，桌面容器为视口的 90%；小屏为 89%。标题使用响应式字号与紧凑字距，正文保持完整阅读空间。
- 按钮 6px 圆角、截图面板约 8px、工具模块约 13px；层次来自边框和与底色相近的阴影。不会为所有内容套同一种卡片。
- 单色、低对比度插件图标加深色底板，保留原 SVG；插件名称、说明、图注与辅助文字在修整轮中提高字号。主窗口透视缩小为约 X 轴 3°、Y 轴 −2°、Z 轴 −1°，保持真实界面可读。
- 页面深浅主题和产品外观演示是两组独立状态。站点主题沿用 `enest-site-theme`，没有显式偏好时跟随系统；外观演示切换真实截图。

## 信息结构与四个舞台

桌面增强模式需要宽度至少 900px、高度至少 650px，且系统未要求减少动态效果。四个章节在导航下方固定展示；其它章节保持普通内容流。

| 章节 / 锚点 | 桌面滚动高度 | 画面与行为 |
| --- | --- | --- |
| 工具聚合 `#intro` | 240vh | 代表插件模块向工作台聚合，主窗口逐步展开、趋于正面；下载按钮不随动效隐藏 |
| 窗口形态 `#features` | 320vh | Quick 小窗 → 主工作台 → 独立窗口，每个形态有完整停留画面；点击左侧入口跳到对应滚动位置 |
| 双场景 `#scenarios` | 300vh | 前半段日常效率、后半段开发工作；可以直接选择场景和插件，插件预览不会被定时器替换 |
| 个性化 `#personal` | 200vh | 明亮、深色、氛围三种产品外观随滚动展示；手动选择后保留用户选择 |

穿插和收尾内容：

- **插件目录 `#catalog`：**34 个工具的本地静态目录，按效率、开发、设计、媒体、其它筛选；数字与当前结果同步，排除 Hello 与主题示例。
- **日常效率：**屏幕助手为主，剪贴板、翻译与 Markdown 可直接切换预览。
- **开发工作：**数据库为主，SSH、中间件与网络调试台可直接切换预览。
- **权限说明：**敏感能力按需授权、插件私有数据隔离。避免「全部数据不联网」「关闭后绝无后台」等超出实际机制的绝对表述。
- **结尾：**eNest 标志模块收拢，明确下载、GitHub 和插件开发入口。
- **下载页：**共用颜色、字体、导航及页脚，使用平台列表、安装流程和原生 FAQ；下载始终进入真实 Releases，不硬编码未经发布说明支持的版本、包体或最低系统要求。

### 开发场景素材调整

原计划的 AI 供应商切换预览暂由网络调试台替代。当前 CC Switch 的 `.page { display: flex }` 覆盖了 HTML `hidden` 的默认表现，隔离预览中会同时显示多个页面，不适合作为首页主展示。`CC Switch` 仍保留在完整插件目录；本轮官网改动不修复或掩盖插件业务问题。网络调试台使用真实未发送请求的初始界面。详情见 [资源说明](assets/ASSETS.md)。

## 动效与交互约定

使用原生滚动、CSS 透视、Web Animations API 和 IntersectionObserver，无滚轮拦截、虚拟滚动或额外动画库。

| 档位 | 场景切换 | 首屏入场 | 使用条件 |
| --- | --- | --- | --- |
| 高 | 340ms | 最长 850ms | 满足桌面舞台条件 |
| 中 | 280ms | 450ms | 移动端或短屏正常流 |
| 低 | 0ms | 0ms | 系统减少动态效果 |

- 短交互使用 180ms 左右的反馈，其他定时转场不超过 450ms；首屏聚合总时长小于 1 秒。滚动变换直接按滚动位置计算，不自动循环播放内容。
- 滚动、resize 与 IntersectionObserver 等事件按需请求一次 requestAnimationFrame，仅更新活动章节；静止时不持续调度动画帧，窗口在后台时暂停。图片、字体加载和历史恢复也会触发位置重算。
- 双场景的默认截图随滚动最多放大 12%，屏幕助手聚焦标注区域，数据库的观察点由编辑区域推进到结果区域；用户手动选择插件后保留该选择，停止默认细节推进。
- 导航可跳过长舞台。窗口形态和场景入口保留可用的 URL 锚点；未增强时直接跳到对应内容。
- 截图按钮支持大图对话框、Escape 关闭和关闭后的焦点返回。筛选、预览与外观选项显示当前选择；所有主要交互可通过键盘访问。
- 仅当前桌面场景可被聚焦，隐藏面板设置 `inert` 和 `aria-hidden`，正常流模式恢复可访问性。

## 降级与静态部署

- **移动端及短屏：**取消长距离固定舞台，三种窗口形态和两类使用场景均按正常内容流排列；保留短入场和手动切换。小屏查看大图入口直接可见。
- **减少动态效果：**使用完整静态排版，关闭滚动透视变换与过渡动画；内容、锚点、筛选和下载入口继续可用。
- **JavaScript 不可用：**核心介绍和插件目录在 HTML 中，默认不隐藏窗口/场景。移动导航仍可见；下载链接不依赖脚本。交互式筛选和大图弹窗属于增强能力。
- **字体或图片失败：**保留系统字体回退、图片替代文字及主要文字内容；加载失败不应阻断导航和下载。
- **零构建：**`index.html` 与 `download.html` 直接引用本地 CSS、JS、WebP、SVG 和 WOFF2，部署根为 `docs/site/`，兼容域名根与 `/eNest/` 子路径。插件开发文档保持原 Docsify 结构。
- **边界：**不新增后端 API、不修改插件协议、不接入分析服务，不自动提交、推送或发布。素材采集使用隔离预览，不对用户业务数据进行操作。

## 独立视觉审阅与本轮修整

独立审阅由 `/root/visual_critic` 在全新上下文、未读取实现源码的情况下完成，以 Raycast、Things、Linear、CleanShot 四个产品页面作为基准，比较首屏截图。该轮中 eNest 的首屏排名为 **4 / 5**；这是一轮外观判断，不是功能或性能得分。

审阅指出：软件窗口较淡、下载 CTA 距离标题较远、工作台展示存在空白、屏幕助手示例用途不够明确，以及小字号和弱对比度图标影响识别。

随后完成一轮修整：缩小主窗口倾斜、将 CTA 向标题靠近、为弱对比度单色图标增加深色底板、提高插件信息和图注字号，并重新采集屏幕助手，用真实 UI 绘制的箭头和矩形框展示标注用途。素材来源及演示边界见 [资源说明](assets/ASSETS.md)。

已完成的是一次独立审阅和对应修整；尚不据此声明排名提高、所有发现已关闭或复评通过。具体检查结果与剩余限制见 [VALIDATION.md](VALIDATION.md)。
