# 开发加载与热更新

开发注册不会复制或安装插件，也不会执行 npm 命令。壳只读取标准文件或连接明确配置的开发服务器。

## Vue、React 与 Vite

1. 在插件目录执行 `npm install`，然后 `npm run dev`。
2. 壳设置 → 开发者，选择含 `plugin.json` 的源码目录。
3. 默认读取 `development.main`；也可以选择“连接开发服务器”，填写 IP、端口或完整 URL。
4. 加载后立即打开壳内插件页。HMR 由 Vite 处理；开发服务器无需已有 `dist`。

```json
{
  "development": { "main": "http://127.0.0.1:5173/" }
}
```

开发地址覆盖值保存于开发注册记录，不修改源码。支持明确配置的局域网地址；只放行该 origin 及其 HMR WebSocket。远程服务器需要自行配置监听地址、防火墙和 HMR 主机。不要把 Vite 的 `0.0.0.0` 监听地址填成实际访问地址。

修改 preload 或主进程必须重启壳；普通插件页面的 HMR 不需要重启。更换服务器地址后重新加载开发注册，旧视图会关闭并创建新的权限边界。

## 原生静态源码

选择“静态源码”时，不连接服务器。公开映射固定为：

| 页面 URL | 源码文件 |
|---|---|
| `index.html` | 根 index.html |
| `src/**` | 根 src/** |
| `assets/**` | public/assets/** |

只支持浏览器能直接运行的 HTML、JS、CSS。TS、JSX、Vue 单文件组件和 npm 裸模块导入需要构建工具。`.git`、`.env`、package.json、node_modules 不由源码协议提供。

壳不监听文件变更。保存后点击对应插件的“重新加载”，或启用“退出即杀”后重新进入。开发插件默认不参加普通闲时休眠/LRU，避免中断 HMR；停止调试会释放实例，移除只删除注册记录，不删除源码。

## 发布前预览

执行插件构建，再选择“预览 dist 构建产物”。此模式使用生产 CSP 和标准产物路径，不复制安装。最后应解包 `.enestplugin` 再验一次，确认资源、图标、README 和截图均不依赖源码树或外部 CDN。

服务器未启动时显示加载失败；启动服务器后重新加载。不要通过关闭沙箱、放开任意 localhost 端口、加载 file:// 或增加宿主文件监听解决白屏。

日志与 DevTools 针对列表中的指定插件操作。自动测试使用独立 `ENEST_TEST_DATA_ROOT` 与 `ENEST_TEST_USER_DATA`，不污染用户数据。
