# eNest 产品官网与插件文档

`docs/site/` 是 GitHub Pages 的发布根目录。产品官网使用原生 HTML、CSS 和 JavaScript，无安装依赖和构建步骤；`plugin/` 使用 Docsify 提供插件开发文档。

## 产品说明

eNest 是插件化桌面壳。业务工具由插件提供；宿主负责窗口、生命周期、权限和共用原生能力。默认主题随壳编译，第三方工具与主题按需安装。

| 能力 | 网站说明边界 |
| --- | --- |
| 窗口与 Quick | 插件可以在 Quick、主窗口标签页、独立窗口和自由面板中使用。默认 Quick 提供搜索、拼音匹配与内容入口；具体入口由插件声明。 |
| 自由面板 | 默认关闭，可在设置的「主题 → 自由面板」分区开启。支持拖动、缩放、对齐、布局保存与恢复；底板材质与不透明度为壳级共用设置，支持完全透明。显示器变化时调整到可用工作区，不承诺不同系统的窗口行为完全相同。 |
| 主题 | 主题定义外观，并可贡献首页、Quick、窗口导航和设置页。启动流程与受保护原生操作仍由宿主负责，不把主题能力描述成任意替换原生界面或运行启动脚本。 |
| 动态设置 | 插件可注册壳内设置项，也可提供自己的设置页面。第三方主题只读取允许共享的描述符，敏感设置保留在可信宿主界面。 |
| 私有存储 | 宿主管理插件私有记录、图片和文件输出；按插件隔离、跨窗口共用。持久化回执不是云同步，也不是任意本机文件访问权限。 |
| MCP | 已有开发接口与本机服务，默认关闭，原生管理入口尚未提供。不得宣传为已经交付的最终用户开关或所有插件自动可调用。 |

能力说明以当前源码及 [插件开发文档](plugin/) 为依据，不以截图或开发版本号推断发行状态。接口详情见 [主题](plugin/themes.md)、[首页](plugin/home.md)、[存储](plugin/storage.md)、[权限](plugin/permissions.md) 与 [MCP](plugin/mcp.md)。

## 文件组织

```text

    theme.js               站点主题恢复与系统跟随
    site.js                共用导航、移动菜单与截图灯箱
    landing.js             首页轨道、Quick、面板排列与目录筛选
    catalog.json           官方插件 manifest 的静态展示快照
    icons/                 产品标志
    plugins/               官方插件图标快照
    screens/               原生截图与保留的既有版本展示素材

    fonts/                 本地字体、来源与许可证
    ASSETS.md              资源来源、许可与展示边界
  plugin/                  Docsify 插件开发文档
```

## 内容与资源维护

- 使用瓷白 `#F5F7F4`、石墨 `#18251F` 与品牌绿 `#3C7D64`；浅深模式共用布局，下载页专有布局在 `assets/download.css`。普通内容维护不要另起视觉系统。
- 产品叙述围绕「用插件组合自己的工作台」：按需安装工具，用 Quick 临时处理事情，把常用插件放进主窗、独立窗口或自由面板。说明具体用法，不把窗口组合写成插件间自动传递数据或执行工作流。
- 官方目录当前为 **37 个插件**：效率 12、开发 17、设计 4、媒体 2、其它 2，包含以插件形式分发的官方主题「素描本」。默认内置主题不计入该目录。
- 目录来源是仓库根目录下的 `eNest_plugin/plugins/*/plugin.json`。更新时同步 `assets/catalog.json`、对应图标和首页静态卡片；名称、分类、ID 与 manifest 对齐。网页可使用不夸大能力的简短说明。
- 首页保留完整静态目录，即使 JavaScript 不可用也能阅读。脚本增强轨道定位、分类筛选与显示计数；`#plugin-{slug}` 和既有插件 ID 锚点均保留。网站运行时不读取开发目录或远程插件索引。目录快照不代表这些插件已随某个公开发行包提供。
- 原生截图使用独立演示数据，生成背景不重绘软件界面；网页上的窗口排布属于交互演示。截图只能证明采集时的界面状态，不能证明跨平台原生能力均已验收。旧截图不冒充当前版本。详细来源与素材提示词见 [资源说明](assets/ASSETS.md)。
- 替换截图时同步 HTML 中的真实宽高与资源版本查询；页面引用的内容哈希用于避免沿用旧素材缓存，不改变资源文件名。
- 字体使用本地文件与系统回退。新增中文字符可由系统字体补齐，不因文案变更要求下载工具或完整 CJK 字体。
- 站点主题偏好存于 `enest-site-theme`，由 `theme.js` 统一管理；这与桌面应用的主题插件是两套独立状态。
- 保留导航、锚点、键盘操作、减少动态效果和无 JavaScript 的阅读路径。Docsify 的 CDN 配置位于 `plugin/index.html`；产品页资源本地化不意味着开发文档已经离线化。

## 交互维护

- 全页使用原生滚动。桌面首屏展示 34 枚精选插件图标，完整目录为 37 个插件；三条轨道周期仍为 22、28、34 秒。421–700px 窄屏展示 16 枚，420px 及以下展示 12 枚，使用 24、30 秒周期的双环，不因窗口变窄停用动画。轨道中心穿过主窗中部，按 18° 低俯视角投影 X/Z 圆环，以统一深度处理远近缩放和主窗前后遮挡。图标保持真实原图，以 CSS 透视、薄侧边和柔和投影呈现立体感；主窗以 6.5 秒周期、4.5px 振幅轻微上下悬浮。
- 主窗默认倾斜悬浮，鼠标移入后平滑转为正面并轻微抬起、放大，不再跟随指针倾斜；移开后恢复原姿态。插件图标仍按指针位置倾斜、抬起，移开后恢复。具体图标的悬停和键盘可见焦点暂停公转，倾斜与回正仍能完成；点击主窗仍可放大，点击图标仍定位到目录。动画复用一个持续帧调度器，离屏、后台或减少动态效果时停止；图标命中范围在移入或布局变化时缓存，不逐帧测量。
- 首屏使用独立布局与绘制边界，可见范围扣除固定导航栏的实际高度，避免首屏已被导航遮住却仍持续动画。仅在可见时保留动画表面的合成提示，离屏、后台和减少动态效果时释放。轨道只在深度顺序变化时更新遮挡层级；交互回弹仅更新仍在变化的表面，相同样式不重复写入。截图异步解码，不以减少图标或降低帧率替代性能优化。
- Quick 首次可见时自动演示一次，结束保留结果，支持步骤选择与重播。用户选择不被重新进入视口覆盖；网页不接入本机快捷键、剪贴板或 eNest 服务。
- 自由面板提供「专注／并行」排列和复位；把手可拖动，键盘方向键移动、Home 复位。移动端使用静态概览与单窗口切换，不模拟拥挤的拖拽桌面。
- 减少动态效果时停止公转、悬浮与自动播放，保留全部操作和静态内容。截图用原生 `dialog` 放大，关闭后恢复触发点焦点；无 JavaScript 时图片链接仍可直接打开。
- 主页加载 `site.js` 与 `landing.js`；发布页只加载 `site.js`，不依赖首页场景节点。

## 下载与发行

当前公开版本为 [v0.0.1](https://github.com/hyqf98/eNest/releases/tag/v0.0.1)，于 2026-10-30 发布。下载页链接到该正式标签的 8 个安装附件：macOS arm64/x64 各有 DMG、ZIP，Windows x64 提供 EXE、ZIP，Linux x64 提供 AppImage、deb；不将更新索引、blockmap 或发布清单当作安装包。

该版本 macOS 包没有 Apple Developer ID 签名和苹果公证，Windows 包未配置开发者代码签名。下载页需保留系统信任提示与校验来源说明，不建议关闭系统全局安全检查。附件已发布不等于全部功能完成跨平台运行验收；翻译前缀文本自动填入等已知问题以发布说明为准。

发布新版本后，依据真实发行记录更新状态、平台附件和兼容性说明。不要把 `package.json` 中的开发版本当成已发布版本，不猜测附件 URL、包体大小或最低系统要求；没有对应平台附件时应明确说明。

## 本地预览

使用已有 Python 环境，在仓库根目录启动静态服务：

```bash
python3.13 -m http.server 8080 --bind 127.0.0.1 --directory docs/site
```

- 产品首页：<http://127.0.0.1:8080/>
- 下载页：<http://127.0.0.1:8080/download.html>
- 插件文档：<http://127.0.0.1:8080/plugin/>

使用 HTTP 而非 `file://`。站内资源使用相对路径，可部署在域名根目录或 `/eNest/` 等子路径。

## 发布站点

`.github/workflows/deploy-pages.yml` 将 `docs/site/` 上传为 Pages 静态产物。仓库 **Settings → Pages → Build and deployment → Source** 应选择 **GitHub Actions**；相关文件推送到 `main` 后由该工作流部署，也可手动触发。

站点更新与桌面发行是两回事：Pages 部署不会生成或发布桌面安装包，也不表示插件或原生功能已经验收。维护网站不要求自动提交、推送或发布。
