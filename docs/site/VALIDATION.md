日期：2026-10-15。验收范围为产品首页、下载页及其本地资源；按用户随后要求，与工作区现有代码和技术文档一并纳入本地提交，不推送或发布。官网重设计没有修改宿主及插件业务实现，相关改动由各自的工程验收记录说明。

- 下载页使用真实 GitHub Releases 入口，清除固定版本、包体大小和未经确认的系统要求。

## 降级与部署

在临时 QA 服务中测试，生产站点没有加入这些测试分支：

- **JavaScript 不可用：**CSP `script-src 'none'`；390px 下导航直接可见，全部窗口/场景内容保留，下载链接可进入下载页。
- **减少动态效果：**测试 fixture 在加载前模拟 `matchMedia('(prefers-reduced-motion: reduce)')`。页面进入 `data-anim=low`，不启用 immersive，三种窗口和两类场景全部可见。CSS 媒体规则另经源码检查；未修改操作系统设置，不能把此项称为操作系统级验收。
- **字体失败：**字体请求返回 403，系统字体仍完整显示标题、介绍和下载按钮。
- **子路径：**`/eNest/` 下首页、下载页、文档和本地资源正常；实际点击进入 Docsify 文档，导航及正文加载正常。文档继续依赖既有 CDN，不属于完全离线站点。
- **真实外链：**GitHub 仓库、Releases 和 Releases/latest 的 HTTP 检查返回 200；latest 当前重定向到 Releases 列表。未下载或安装应用。

## 边界

- 宿主截图使用真实 renderer 和隔离演示 fixture，浏览器 iframe 代替原生 WebContentsView。没有在本轮验证 Electron 原生窗口、置顶、快捷键或真实数据库/SSH 连接。

- 后台暂停和仅更新活动章节有实现与源码核验，未进行独立 CPU/FPS 性能剖析；未覆盖 Firefox、Safari、真实移动设备或屏幕阅读器。
- 没有实际部署 GitHub Pages。保留本地预览即可复核，发布仍由项目现有流程执行。
