eNest 是插件化桌面壳子：市场一键安装，多 Tab 独立进程运行， 关闭即回收。适合效率工具、开发者工具与内部工作台。

开始开发插件 查看 API
Isolation

会话与进程隔离

每个插件独立 WebContentsView 与 persist:plugin-{id}，Cookie / 本地存储互不干扰。

Tabs

多 Tab 并行

顶部 Tab 切换插件页面；关闭 Tab 立即销毁渲染进程，内存干净可预期。

ZAPI

白名单插件 API

preload 注入 window.enest，按 plugin.json 的 permissions 校验 IPC。

Theme

可主题化壳子

浅色 / 深色 / 跟随系统；Token 可调，支持背景图与视频；主题插件可动态注册。

Devtools

开发者控制台

本地目录热加载、Vite HMR、DevTools 一键打开，对标 uTools 开发台体验。

Data

本地优先数据

数据根目录 ~/eNest，SQLite（sql.js）写入 data/enest.db。

Quick start

三分钟跑通第一个插件

从市场打开示例，或在开发者页「加载本地目录」指向含 plugin.json 的文件夹。
