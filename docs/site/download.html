从源码构建

适合贡献者与需要定制壳子的团队。需要 Node.js 与 npm。

git clone https://github.com/hyqf98/eNest.git
cd eNest
npm install
npm run dev        # 开发
npm run dist       # 本机打包

系统要求

  • macOS 11+（Intel / Apple Silicon）
  • Windows 10 / 11 x64
  • 主流 Linux 发行版（glibc 较新）
  • 磁盘：安装包 < 90MB；数据目录 ~/eNest
首次启动会创建 ~/eNest（plugins / data / themes / settings.json）。
