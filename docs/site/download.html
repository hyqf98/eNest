常见问题

安装与使用
常见问题

为什么系统提示未知开发者？

本次 macOS 包没有 Apple Developer ID 签名，也未完成苹果公证；Windows 包未配置开发者代码签名。系统可能提示未知开发者或阻止打开。请先核对仓库来源和文件摘要，再决定是否安装；不要为运行 eNest 关闭系统的全局安全检查。受管理的电脑还需遵循管理员策略。

Mac 应该选择哪个架构？

在苹果菜单中打开「关于本机」。Apple M 系列芯片对应 arm64，Intel 处理器对应 x64。根据文件名中的架构标记选择附件。

可以添加自己的工具吗？

可以。业务工具与第三方主题都通过插件提供。如果想开发自己的插件，可从插件快速开始了解接入方式；官网目录是源码项目的展示，不代表某个发行包已包含全部插件。

自由面板会记住桌面布局吗？

自由面板默认关闭，在「设置 → 主题 → 自由面板」开启。插件组件可以移动、缩放和对齐，面板布局独立保存；重新启动时恢复，显示器变化时会将窗口调整到可用工作区。底板材质与不透明度在同一分区调整，支持完全透明。实际窗口行为取决于系统与显示器配置。

主题能改变什么？

主题定义外观，也可以贡献首页、Quick、窗口导航和设置页。账号、权限、路径与媒体选择等受保护操作仍由可信宿主界面处理；主题只接收允许共享的设置。详见主题开发指南。

插件数据与权限如何管理？

记录与设置、图片资产和文件输出按插件隔离，同一插件的不同窗口共用数据。私有存储不等于云同步，也不授予任意本机文件访问权。插件原生后端需要另行授予完整本机信任；具体能力见权限标准和存储标准。
