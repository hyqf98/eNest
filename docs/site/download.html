BEFORE YOU START

几个小问题。

Mac 应该选择哪个安装包？

打开苹果菜单中的「关于本机」。如果显示 Apple M 系列芯片，选择 arm64；如果显示 Intel 处理器，选择 x64。文件名中的架构标记可以帮助你区分。

下载按钮为什么打开 GitHub？

eNest 通过 GitHub Releases 分发安装包和版本说明。进入发布页后，展开 Assets，选择与你的操作系统和设备架构对应的文件。

可以添加自己的工具吗？

可以。eNest 支持通过插件扩展工作台。已有工具可以从插件市场安装；如果想开发自己的插件，从插件快速开始阅读接入方式。
