BEFORE YOU START

几个小问题。

Mac 应该选择哪个安装包？

打开苹果菜单中的「关于本机」。如果显示 Apple M 系列芯片，选择 arm64；如果显示 Intel 处理器，选择 x64。文件名中的架构标记可以帮助你区分。

下载按钮为什么打开 GitHub？

GitHub Releases 是 eNest 的公开发行入口。目前尚无公开发行版，因此按钮指向发行列表，而不是不存在的安装包。源码中的开发版本号不代表已经发布。

可以添加自己的工具吗？

可以。eNest 支持通过插件扩展工作台。已有工具可以从插件市场安装；如果想开发自己的插件，从插件快速开始阅读接入方式。

自由面板会记住桌面布局吗？

自由面板默认关闭，在「设置 → 通用 → 自由面板」开启。插件可以移动、缩放和对齐，面板布局独立保存；重新启动时恢复，显示器变化时会将窗口调整到可用工作区。实际窗口行为取决于系统与显示器配置。

主题和插件设置如何扩展？

主题集中定义外观，也可贡献首页、Quick、窗口导航和设置页。插件可把设置项注册到壳，或提供自己的设置页面。主题只接收允许共享的设置，账号、权限、路径与媒体选择仍由可信宿主界面处理；启动流程也由宿主管理。

插件数据保存在什么地方？

宿主提供统一的插件私有存储：记录与设置、图片资产、已完成的文件输出按插件隔离，并由同一插件的不同窗口共用。开发者可使用持久化回执确认保存。私有存储不等于云同步，也不授予任意本机文件访问权；插件原生后端需要另行授予完整本机信任。详见存储标准。

现在能直接连接 MCP 客户端吗？

当前源码已有插件工具声明、处理器注册和本机 MCP 服务，默认关闭，原生管理入口尚未提供。它不是已交付的用户开关，也不会自动为插件授权。开发者可阅读MCP 工具贡献标准了解接入与权限边界。
